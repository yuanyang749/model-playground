## 一、设计宗旨与核心哲学

### 1.1 IP 基因转译
- **无手脚特性**：没有四肢不是劣势，而是独特的运动美学。所有物理交互（跳、推、拉、打）全部由“**果冻形变（Squash & Stretch）**”与“**泡泡外延（Bubble Extension）**”承载。
- **情感触达**：软萌、治愈、弹性、高反馈。每一次触碰墙壁、起跳着陆，都能让玩家隔着屏幕感受到像果冻一样 Duang~Duang~ 的物理韧性。

### 1.2 掌机屏幕环境适配
- 运行在 Game Boy 模拟器视口（约 356×280 物理像素区间），视口紧凑。
- **减法设计原则**：**“大色块、大颗粒、零杂质、强功能”**。坚决剔除一切干扰判断的微碎装饰，将全屏视觉重心让渡给主角的弹性形变与泡泡轨迹。

## 二、角色关键动效与果冻弹性物理规范

没有四肢的角色，动画的精髓在于**体积守恒（Volume Conservation）**与**阻尼弹簧振荡（Damped Spring Oscillation）**。当高度受压变矮时，宽度必须等比膨胀扩张。

```
    【正常待机】           【蓄力起跳/下砸】           【离地拉伸飞升】
     w=1.0, h=1.0            w=1.4, h=0.6              w=0.75, h=1.4
         ▲                       ▲                          ▲
        / \                     /---\                      / | \
       /   \                   (  .  )                    |  .  |
      (  .  )                  (_____)                    |     |
      (_____)                                             (_____)
```

### 2.1 基础弹性物理公式 (Squash & Stretch Model)
角色形变比例缩放遵循阻尼正弦回弹：
$$S_y(t) = 1 + A \cdot e^{-\zeta \omega t} \cdot \cos(\omega_d t)$$
$$S_x(t) = \frac{1}{\sqrt{S_y(t)}} \quad (\text{保持视效体积恒定})$$
- 落地冲击初速度衰减周期：约 0.28 秒，回弹 2 次后归位，带来极度舒适的果冻肉感。

---

### 2.2 六大核心关键动效拆解 (Key Animation Frames)

#### ① 待机果冻呼吸 (Idle Breathing) —— 4 帧循环 (60fps / 每周期 1.8s)
- **动作表现**：原地像新鲜出炉的布丁一样极轻微地上下起伏（$S_y$ 在 0.96 到 1.04 之间平滑缓动），头顶的小水滴尖尖随惯性微幅滞后摆动。
- **随机微表情**：每隔 4~6 秒随机触发一次“单眼微眨”或“脸颊粉色腮红微亮”。

#### ② 无手脚蠕动步态 (Roll & Hop Gait) —— 6 帧循环
- **Frame 1 (蓄势)**：身体整体略向移动方向倾斜，底部与地面接触面扁平化（$S_x=1.15, S_y=0.9$）。
- **Frame 2 (弹射)**：身体像水滴一样向前上方“扑哧”伸展飞起（离地 3~4 像素）。
- **Frame 3 (拉长)**：空中阶段拉长为水滴流线型（倾斜 15度，宽高比 0.85 : 1.2）。
- **Frame 4 (触地)**：前脚掌（底部前缘）着地，身体大幅度下压变形吸收冲击（$S_x=1.3, S_y=0.7$）。
- **Frame 5-6 (回弹)**：迅速回缩为球形，准备进入下一个滚动节律。

#### ③ 蓄力跳跃与触地反馈 (Squash Jump & Landing)
- **起跳前摇 (120ms)**：按 A 瞬间，身体像面团一样猛地下沉压扁至 $S_y=0.55, S_x=1.45$，两腮肉感外溢，眼睛眯成两道弯月弧线 `(> <)`。
- **升空瞬间 (40ms)**：势能释放，如火箭般向天花板拉伸射出，达到最高伸展度（$S_y=1.45, S_x=0.75$）。
- **最高滞空点 (Peak)**：重力加速度为 0 瞬间，恢复标准 1.0 完美球体，头顶尖尖由于惯性向上飘晃一下。
- **落地冲击 (Heavy Land)**：踩到地面的第一帧剧烈拍扁（$S_y=0.5, S_x=1.5$），地面向两侧溅射 2 颗半透明白色像素尘埃微粒；随后经历 2 次小幅震颤（Duang~）平息。

#### ④ 深吸蓄力吐泡泡 (Inhale & Bubble Spit)
- **蓄气前摇 (80ms)**：小软身体向内紧缩收紧（全身缩水至 0.85x），双颊急速膨胀鼓起成两颗圆球，嘴巴紧闭。
- **喷吐爆发 (30ms)**：
  - 嘴巴猛地张大变成圆形“O”型；
  - 角色身体因反作用力**向后产生 3 像素微退**并微扁；
  - 一颗表面泛着反光高光的透明像素泡泡“啵~”地脱口而出。

#### ⑤ 极窄缝隙挤压滑行 (Pipe Squish Glide)
- **按“下”触发**：当进入 1 格高的狭窄管道或缝隙时，身体不再保持立姿，而是被压缩成一张扁平流体薄饼（高度仅为原先的 35%，宽度延长到 180%）。
- **滑行动画**：像软糖一样顺着管道内壁“滋溜”滑行通过，头顶水滴尖拖在尾端随风摆荡，滑出管道瞬间“嘭”地一声膨胀弹回原形。

#### ⑥ 领队轮换切人动效 (Leader Switch Poof)
- 按 SELECT 切换领队时，当前小软像肥皂泡一样在原地化作一圈细碎彩色星光并迅速下沉；
- 新领队小软伴随着一声清脆的“Plop!”，在空中打着旋（360° 果冻翻滚）从天而降接管主控位，其余小伙伴排在身后跟随。

## 三、泡泡视觉与动力学系统

泡泡不仅是贴图，更是具备弹力与张力的独立物理实体。

```
       [ 生成 ]             [ 悬浮巡航 ]             [ 负载承重 ]             [ 破裂消散 ]
    口中膨胀脱离            微幅正弦波起伏            顶部凹陷 30%            4-6颗水珠溅射
        (o)                     (   )                   ( v )                    *  .
       /   \                   (  *  )                 (  *  )                 .  *  .
```

### 3.1 泡泡动态四阶段
1. **生成期（Inflation）**：由 4×4 像素极速膨胀到 18×18 像素，与嘴唇剥离瞬间有透明水膜拉丝断裂细节。
2. **漂浮期（Perlin Drift）**：悬停在空中时，以 $y = y_0 + 2\sin(3t)$ 的低频正弦微幅上下游弋，模拟真实空气浮力。
3. **承重形变（Deformation under Load）**：
   - 当小软跳到泡泡上方时，泡泡顶部受压产生 30% 弧度凹陷，蓄积反弹势能；
   - 0.15 秒后，泡泡猛烈向上恢复原状，将小软当成弹簧弹射至高空。
4. **破裂特效（Pop! Dispersal）**：
   - 泡泡外壁破裂，向八个方向喷溅出 6 颗带重力下落的浅色微粒，伴随白噪声清脆音效，0.2 秒内淡出。

### 4.2 细节删减与“做减法”原则（防止视效杂乱）

| 元素分类 | 必须保留的核心信息 | 坚决剔除/不显示的冗余细节 | 设计理由 |
| :--- | :--- | :--- | :--- |
| **地表与砖块** | 平台顶部的**高反光走线（1px 白色亮边）**，标识可站立区域；底部纯黑阴影。 | 剔除砖块内部繁复的碎石纹理、裂纹杂点、风化颗粒。 | 避免小屏幕上碎点与角色眼睛/泡泡混淆。 |
| **背景层 (BG)** | 低饱和度单色渐变（柔和晨曦蓝/森林浅绿），对比度压至前景的 20%。 | 剔除远景复杂山峦、多层视差滚动的精细树叶、漂浮飞鸟。 | 保证前景中黄色、粉色的小软始终具有最高视认度。 |
| **HUD 界面** | 仅保留当前领队小软彩色头像徽章、钥匙/露珠计数器（极简字号）。 | 剔除传统 RPG 式的长血条、经验值框、多行文字说明卡。 | 最大化释放竖向游戏空间，把舞台全留给平台跳跃。 |
| **危险物 (Hazard)** | 尖刺采用纯色高亮醒目三角形；毒液采用高对比度单色波浪。 | 剔除复杂的渐变毒雾粒子和反光细节。 | 玩家第一眼就能秒懂危险边界，无需凑近辨识。 |

## 五、五彩协同关卡机制与实体交互

关卡核心围绕 **“色彩互补组合拳”** 展开，利用泡泡在屏幕内搭建临时通路：

```
               [ 高处闭锁闸门 ]
                     ▲
                     │ (被大黄重力下压解锁)
         [粉色粘胶泡] ├──[ 💛 黄圆圆 (重力下砸) ]
             ▲       │
             │       └──[ 踩上粉泡借力 ]
         [绿色弹力泡]
             ▲
   [ 💚 绿萌萌 起跳 ]
```

### 5.1 经典解谜连击链 (Combo Mechanics)
1. **搭天梯（粉 + 绿）**：
   - 面对光秃秃的垂直绝壁，切换 **粉嘟嘟** 贴壁吐出 2 颗粘胶泡，粘在岩壁半空；
   - 切换 **绿萌萌** 在地面吐出一颗弹力泡，利用超强弹性跃升至第一颗粉泡上，再二次起跳翻越险峰。
2. **失重吊装（蓝 + 黄）**：
   - 遇到巨大的石门与深渊，切换 **蓝波波** 吐出水泡包裹地面的巨石，石块受浮力缓慢升空；
   - 切换 **黄圆圆** 跳上漂浮的石块，以其体重稳住石块平衡，像空中缆车一样渡过深渊。
3. **连锁扫除（蓝 + 紫）**：
   - 蓝波波连续吐泡将成群的灰泥杂兵逐一包裹禁锢在半空；
   - 切换 **紫葡萄** 吐出星光裂变泡命中其中一颗，引发轰轰烈烈的连环大殉爆（Pop-Pop-Pop!），全屏清场并炸开封印水晶。

## 六、手柄按键映射与触控优化方案

在手机 Game Boy 模拟器与触控环境下，操作指令保持极度极简克制：

```
           [ D-Pad 十字键 ]                      [ 操作键群 ]
         ▲ : 向上轻瞄准                         
      ◀     ▶ : 左右 Q 弹翻滚滚动                ( B ) : 吐出当前属性泡泡 (蓄力增大)
         ▼ : 身体扁平化 / 钻狭缝 / 踩破泡泡        ( A ) : 蓄力起跳 / 弹性跃升
                                               
       [ SELECT ] : 顺时针一键轮换领队小软       [ START ] : 暂停游戏 / 呼出小地图
```

### 6.1 触觉反馈增强规范 (Haptic Feedback)
- **吐出小泡泡**：轻微敲击脉冲（`navigator.vibrate(8)`），带来像戳破小水珠的微脆触觉；
- **果冻落地 Duang~**：双连轻颤（`navigator.vibrate([12, 30, 8])`），模拟布丁回弹；
- **紫泡大连爆**：重度爆破震感（`navigator.vibrate([40, 20, 60])`），营造极其爽快的打击感。

## 七、开发路线图规划 (Roadmap)

1. **Phase 1: 物理核心与形变引擎**
   - 实现无手脚小软的 Squash & Stretch 顶点形变着色器/Canvas 缩放矩阵；
   - 调校落地、撞墙的阻尼弹性回荡系数。
2. **Phase 2: 五彩泡泡物理实体**
   - 建立固体泡（金）、浮力泡（蓝）、粘性泡（粉）、弹性泡（绿）、裂变泡（紫）的状态机与碰撞箱。
3. **Phase 3: 粗颗粒单屏谜题房 (Single-Screen Puzzle Rooms)**
   - 制作 16×12 极简高对比度关卡，验证 5 色连击解谜闭环。
