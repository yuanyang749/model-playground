> **创建模型**：`Gemini 4 Hydrogen`（`thinkingLevel: MAX`，One-shot 单次端到端直出，零人工修改）

经典的 LLM 空间几何与物理运动学基准测试——**「一只骑自行车的鹈鹕（A Pelican Riding a Bicycle）」** 高帧率交互式单页 SVG 动画。

## 运行

零外部依赖、单文件自包含（HTML + CSS + SVG + 原生 JS + Web Audio API），直接双击 `index.html` 或通过静态服务打开即可：

```bash
cd pelican-bike
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 核心特性

- **三组实时 2D 双连杆逆运动学（2-Link IK）**：基于余弦定理实时解算左右双腿（髋-膝-踝）与握把翅膀（肩-肘-腕）关节坐标，双脚蹼 360° 全程锁死在踏板圆周轨迹上，零脱节零穿模。
- **精细自行车机械结构与多层空间遮挡**：复古钻石车架、下管水壶架、前后车灯、对称轮毂反光片与动态闭合链条；远景腿、车架、近景腿遮挡层次严密。
- **昼夜三主题视差海滨场景**：支持 `☀️ 晴朗海风`、`🌅 落日熔金`、`🌙 星夜巡航`（自动点亮体积光车头灯与远方旋转灯塔光束）。
- **趣味物理与声学交互**：无级变速滑块、`⚡ 全力冲刺 Turbo`（前倾飙汗与破风线）、`🦴 IK 骨骼/关节透视` 实时遥测面板、`🐟 投喂小鱼`（抛物线飞入半透明弹性喉囊）及 Web Audio 合成清脆车铃声。
