# VOXEL STRIKE · 方块突击

**VOXEL STRIKE（方块突击）** 是一款纯前端零构建、基于 **Three.js + WebGL** 与 **Web Audio API** 从零打造的《我的世界》（Minecraft）风格 3D 第一人称体素波次生存射击游戏。

所有像素贴图、地形网格、3D 武器与怪物模型、粒子特效、昼夜天空以及 3D 空间音效均由代码实时程序化生成，无任何外部纹理或音频资源依赖。

---

## 快速启动

```bash
cd voxel-strike
python3 -m http.server 5179
```

在浏览器中打开 <http://localhost:5179> 即可开始游玩。

## 核心特性

### 1. 程序化体素世界与实时破坏
- **海岛前哨地形**：基于多层分形 Simplex 噪声（FBM）生成 $96 \times 48 \times 96$ 的体素岛屿，包含沙滩、草地、森林、高山积雪、煤矿脉以及中央木质前哨站与矮砖掩体墙。
- **16×16 像素纹理图集**：程序化绘制 12 种方块材质（草方块、泥土、石头、圆石、沙子、橡木原木、橡木树叶、砖块、木板、雪块、煤矿石、基岩），采用 `NearestFilter` 呈现纯粹的像素颗粒质感。
- **分块网格与平滑环境光遮蔽（Vertex AO）**：按 $16 \times 16$ 区块（Chunk）剔除隐藏面，计算 4 级逐顶点环境光遮蔽（Ambient Occlusion）并自动翻转四边形对角线消除插值伪影。
- **动态地形破坏与建造**：支持使用钻石镐挖掘方块、右键放置砖块修筑工事，以及火箭筒 / TNT 爆破怪造成的球形爆炸弹坑与海水倒灌。

### 2. 四种武器与独立 3D 视图模型（Viewmodel）
| 键位 | 武器 | 特性 |
| :---: | :--- | :--- |
| `1` | **方块步枪** | 全自动连发射击（600 RPM），支持右键开镜瞄准（ADS 精准收束与视野缩放） |
| `2` | **泵动霰弹枪** | 近战高爆发（单发 8 颗弹丸扇形散射），大后坐力与击退 |
| `3` | **火箭发射器** | 发射带尾焰烟迹的物理实体火箭弹，命中后产生球形范围爆炸并炸毁地形方块 |
| `4` | **钻石战镐** | 近战劈砍 / 持续挖掘任意可破坏方块（采集砖块） / 右键放置砖块修筑掩体 |

### 3. 四类体素怪物与 Boss 战
- **腐尸（Zombie）**：近战追击，遇高墙会自动跳跃或挥臂拆毁玩家修筑的掩体方块。
- **TNT 爆破怪（Creeper）**：头顶带燃烧引信，逼近玩家后闪烁膨胀并引爆，炸毁周围地形。
- **骷髅射手（Skeleton Archer）**：保持中远距离横向游走，发射带重力下坠的抛物线箭矢。
- **方块巨像（Voxel Golem Boss）**：每 5 波降临的巨型黑曜石 Boss，拥有专属顶部血条，兼具远程投掷巨石（砸出弹坑）与近战震地冲击波。

### 4. 氛围、粒子与 Web Audio 合成音效
- **昼夜循环与像素云层**：实时太阳/月亮轨道路线、星空渐变、无缝平铺的 3D 像素云海、动态阴影与水下蓝绿色雾效。
- **GPU 实例化粒子**：基于 `InstancedMesh` 的方块碎屑飞溅（带重力与地面反弹）、加法混色火花/火焰、半透明爆炸烟雾与弹道曳光。
- **纯合成 3D 空间音效**：使用 Web Audio API 实时合成步枪/霰弹/火箭/挖掘/爆炸/受击/波次号角等全部音效，支持基于距离衰减与立体声声像（Stereo Panning）的方位感知。

## 操作说明

- **移动 / 冲刺 / 跳跃**：`W A S D` / `Shift` / `Space`（水中按住 `Space` 上浮）
- **射击 / 挖掘**：`鼠标左键`
- **瞄准（ADS） / 放置砖块**：`鼠标右键`
- **换弹**：`R`
- **切换武器**：`1` `2` `3` `4` 或 `鼠标滚轮`
- **暂停 / 设置**：`Esc` 或 `P`
- **全屏切换**：`F`

## 目录结构

```text
voxel-strike/
├── index.html          # 游戏主页面、像素风 HUD、主菜单/暂停/结算面板
├── style.css           # Minecraft 风格像素 UI 与响应式 HUD 样式
├── js/
│   ├── main.js         # 渲染管线、波次管理、掉落物、游戏状态机与测试钩子
│   ├── noise.js        # 种子伪随机（mulberry32）与 2D Simplex / FBM 噪声
│   ├── blocks.js       # 12 种方块定义与 16×16 像素纹理图集生成
│   ├── world.js        # 岛屿地形生成、Chunk 网格构建（含顶点 AO）、DDA 体素射线与爆炸
│   ├── physics.js      # AABB 体素分离轴碰撞检测与射线-包围盒求交
│   ├── player.js       # 第一人称运动学、游泳、跌落伤害、镜头摇晃与后坐力
│   ├── weapons.js      # 四种武器逻辑与 3D 像素 Viewmodel 动画
│   ├── enemies.js      # 四类体素敌人建模、AI 寻路/拆墙/射击与 Boss 技能
│   ├── effects.js      # InstancedMesh 粒子系统、弹道曳光与爆炸闪光
│   ├── sky.js          # 昼夜循环、日月星空、像素云层与海面
│   ├── hud.js          # 像素心形血条、武器图标、动态准星、命中反馈与旋转小地图
│   ├── audio.js        # Web Audio API 程序化 3D 空间音效合成器
│   └── input.js        # 键鼠输入与 Pointer Lock 管理
└── vendor/             # 本地打包的 Three.js r186 模块
```
