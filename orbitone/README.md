# Orbitone · 星轨

一座按开普勒定律运转的音乐盒。在轨道上放置行星，每当它们掠过金色子午线，就会唱出一个音符。

## 运行

项目使用原生 ES Modules，需要通过本地 HTTP 服务打开（直接双击 `file://` 会被浏览器拦截）：

```bash
cd orbitone
python3 -m http.server 5178
# 浏览器打开 http://localhost:5178
```

零依赖、零构建：Canvas 2D + Web Audio API。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 点击轨道 | 放置行星（按住越久质量越大、声音越响） |
| 点击行星 | 摘除 |
| 拖动行星 | 换轨；拖出星系即摘除 |
| 滚轮（悬停在行星上） | 调整质量 |
| `Space` / `R` / `C` / `M` | 播放暂停 / 随机星系 / 清空 / 切换模式 |
| `1`–`4` / `↑` `↓` / `S` / `H` | 子午线数 / 速度 / 分享链接 / 说明 |

## 设计要点

- **两种天体力学**
  - 谐振：第 n 条轨道每周期公转整数圈，整首曲子严格循环。
  - 开普勒：T² ∝ r³，转速呈无理数比，节奏像 Steve Reich 的相位音乐一样缓慢漂移、永不重复。
- **采样级精确的节奏**：视觉帧只负责画面；音符时刻按解析式求出（解出行星穿越子午线的精确时间），再借助 150ms 预排程窗口交给 AudioContext 时钟，不受掉帧影响。
- **随轨道旋转的吸附槽位**：行星位置存储为“相对轨道参考系的偏移”，吸附时落入随轨道一起转动的 16 个槽位。因此同一轨道上的行星间隔始终规整，改变速度也不会打乱节奏关系。
- **纯合成音色**：水晶钟（非整数比 FM）、卡林巴、玻璃琴；程序化生成、高频先衰减的卷积混响；附点八分音符的乒乓延迟；以调性主音为根的“恒星底噪”。
- **示波器日冕**：太阳周围的光环就是实时输出的音频波形。
- **分享与录音**：星系完整编码进 URL hash（每颗行星 4 个字符）；还可以一键录下演奏并下载。

## 结构

```
orbitone/
├── index.html
├── style.css
└── js/
    ├── main.js     时钟、调度、交互与界面
    ├── orrery.js   轨道数学：参考系、重定时、解析求交
    ├── audio.js    合成器、效果链、录音
    ├── sky.js      渲染器：星云、轨道、彗尾、粒子
    ├── music.js    音阶、调、配色等常量
    └── share.js    URL 编解码
```
