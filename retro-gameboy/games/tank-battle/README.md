# BATTLE CITY 1990 · 像素坦克大战

**BATTLE CITY 1990（像素坦克大战）** 是一款纯前端零构建依赖、基于原生 **HTML5 Canvas 2D** 与 **Web Audio API** 打造的 FC 经典坦克大战现代复刻与物理强化版。

所有坦克精灵绘制、关卡地图瓦片、粒子爆炸火花以及 8-bit 复古芯片音效均由代码实时程序化驱动，无任何外部图片或音频素材依赖。

---

## 快速启动

```bash
cd tank-battle
python3 -m http.server 8080
```

在浏览器中打开 <http://localhost:8080> 即可开始游玩。

## 核心技术与架构特性

### 1. 向量解耦碰撞解死锁物理算法 (Vector Decoupling Algorithm)
- **解耦防卡死**：经典游戏中多坦克挤在狭窄通道常出现互相卡死或穿模。本项目在 `physics.js` 中设计了**向量解耦物理检测**：
  - 当两辆坦克中心距小于碰撞阈值时，若坦克的下一步运动向量会使彼此中心距增大，则**判定为离开动作并允许移动**；
  - 配合柔性反穿透推离（Active Depenetration），使挤压在角落的战车能够平滑自然分开，彻底避免卡死死锁。

### 2. 原生 Canvas 瓦片地图系统 (`map.js`)
- **26×26 标准网格**：基于 $16 \times 16\text{ px}$ 单元格，全画幅 $416 \times 416\text{ px}$。
- **经典地形元素**：
  - 🧱 **砖墙 (Brick)**：普通炮弹击碎对应半砖，重炮可摧毁整块。
  - 🛡️ **钢墙 (Steel)**：阻挡普通子弹，升级到三级炮后可打碎。
  - 🌊 **河流 (Water)**：子弹可穿过，坦克无法通行。
  - 🌲 **树林 (Forest)**：半透明遮蔽迷雾，坦克与炮弹隐匿其中。
  - 🦅 **老鹰司令部 (Base)**：守护玩家的核心阵地，被摧毁即游戏结束。
- **5 套精心手绘关卡**：难度阶梯递进，包含不同地形阻隔与防御工事。

### 3. 多兵种 AI 与道具系统 (`entities.js`)
- **4 类 AI 敌方装甲**：
  - **基础轻坦 (Basic)**：行进稳健，提供基础积分。
  - **高速侦察坦 (Fast Scout)**：机动极快，擅长迂回突击。
  - **连发防空坦 (Power)**：射击频率高，压制火力猛。
  - **重装装甲坦 (Armor)**：拥有 4 点耐久护盾，颜色随受损状态渐变。
- **经典掉落道具**：手雷（全屏炸裂敌坦）、定时怀表（全屏冻结）、头盔（无敌防护盾）、铁锨（老鹰基地钢化加固）、五角星（战车火力与射速升级）。

### 4. 纯 Web Audio 8-Bit 芯片音效合成 (`audio.js`)
- **零外部音频文件**：使用 `OscillatorNode`（Square、Triangle、Sine 波）与随机高斯白噪声缓冲区，程序化合成主炮射击、击中砖墙、弹丸撞击钢板、爆破轰鸣、拾取道具与通关号角。
- **触感反馈 (Haptics)**：移动端支持 `navigator.vibrate` 微震动反馈。

## 操作说明

### 💻 PC 键盘操作
| 按键 | 动作 |
| :---: | :--- |
| `W A S D` / `↑ ↓ ← →` | 战车移动（上下左右） |
| `J` / `Z` / `Space` | 主炮开火 (Fire A) |
| `K` / `X` | 极速连发 (Turbo B) |
| `Enter` | 标题界面开始游戏 |
| `P` | 暂停 / 继续游戏 |
| `R` | 重新开始当前关卡 |

### 📱 移动端触控操作
- **左侧滑动十字键 (Tactile Slide D-Pad)**：支持滑动式摇杆盲操，中心带有柔性回弹摇杆指示球。
- **右侧双功能按键**：
  - **A 键（主炮）**：单发精准点射。
  - **B 键（连发）**：按住进行极速连续射击。
- **顶部系统快捷栏**：声音开关、暂停、全屏切换与一键重开。
