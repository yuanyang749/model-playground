# 🕹️ Antigravity Retro Game Boy Console (掌机模拟器)

**Antigravity Retro Game Boy Console（复古掌机模拟器）** 是一款纯前端零构建依赖、高度仿真任天堂初代 Game Boy (DMG-01) 经典掌机的 Web 模拟器与多游戏运行系统。

所有工程塑料外壳微拟物渲染、点阵液晶屏滤镜、8-Bit 芯片音效合成、滑动触控按键与多卡带换卡调度均由代码原生驱动，在浏览器中即点即玩。

---

## 快速启动

```bash
cd retro-gameboy
python3 -m http.server 8080
```

在浏览器中打开 <http://localhost:8080> 即可开机体验。

## 核心硬件特性与架构

### 1. 经典 Game Boy (DMG-01) 掌机仿真外壳
- **拟真人机工学设计**：
  - 经典灰白工程塑料质感外壳，右下角标志性圆弧防滑切角。
  - 屏幕边框“DOT MATRIX WITH STEREO SOUND”经典刻印与红蓝双色饰线。
  - 右下角 30° 倾斜扬声器音孔格栅。
  - 真实开机“*ba-ding!*”清脆晶体音效与硬件电源开关。
- **全套手感实体化触控按键**：
  - **滑动十字键 (D-Pad)**：支持滑动式摇杆盲操与 8 方向无缝连贯导航。
  - **倾斜 A / B 键**：经典 -25° 倾角排布，深酒红烤漆质感，配备设备物理震动反馈（Haptic Vibration）。
  - **SELECT / START 橡胶条按键**：斜排橡胶条质感，用于暂停、开局与换卡复位。

### 2. 多重液晶调色板 (Palette Switcher)
- 🎨 **原彩 (True Color)**：原汁原味的鲜明高饱和度 RGB 街机画质，无额外扫描线干扰。
- 🟢 **经典点阵 (DMG)**：复古橄榄绿液晶屏点阵滤镜，重回 1989 年初代掌机质感。
- ⚪ **Pocket 黑白**：高对比度纯净黑白电子屏风格。

### 3. 多卡带插拔系统 (Cartridge System)
随时切换游戏卡带，无需刷新页面，自动播放换卡引导与复古开机 Chime 音效。

## 操作说明

### 💻 PC 键盘操作
| 按键 | 掌机功能 | 游戏内动作说明 |
| :---: | :---: | :--- |
| `W A S D` / `↑ ↓ ← →` | **D-Pad 方向键** | 移动、菜单上下选择 |
| `J` / `Z` | **A 键** | 确认、开火、跳跃、旋转方块 |
| `K` / `X` | **B 键** | 连发射击、吐泡泡、取消 |
| `Shift` / `Tab` | **SELECT 键** | 切换队长史莱姆、功能切换 |
| `Enter` / `Space` | **START 键** | 启动卡带、暂停 / 继续 |
| `Esc` / `R` | **RESET 键** | 软复位返回掌机多卡带菜单 |

### 📱 移动端触控操作
- 直接触摸 Game Boy 上的**滑动十字键**、**A/B 倾斜键**与 **SELECT/START 键**。
- 点击屏幕边框上的 **◀ 复位 / 目录** 可随时返回掌机卡带选择菜单。
- 底部 Utility Dock 提供 **POWER (开关机)**、**PALETTE (调色板切换)**、**FULLSCREEN (全屏)** 与 **HOME (返回演练场)**。
